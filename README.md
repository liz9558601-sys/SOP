# AI 剧情向视频生产 SOP

李煜 · AI 剧情向视频标准化作业流程展示站。

从竞品拆解到成片交付，六步流水线，配一套可复用的提示词模板。

## 页面

| 文件 | 内容 |
| --- | --- |
| `index.html` | 关于 / 联系方式 / 流程导航 |
| `process.html` | 六步流程 · 避坑指南 · 成片示例 |
| `library.html` | 提示词库（筛选 + 一键复制） |

## 目录结构

```
assets/
  css/main.css        设计系统（配色 / 排版 / 组件）
  js/main.js          导航 · 筛选 · 复制 · 鼠标颗粒
  videos/*.mp4        6 段 TikTok 橱窗号已跑通的成片
```

## 本地预览

```bash
python -m http.server 8123
```

然后打开 <http://127.0.0.1:8123>

## 视频规格

源片为 HEVC 1080p / 4K 60fps，已统一转码为网页优化版：

- 分辨率 720 × 1280
- 编码 H.264 / CRF 26
- 帧率 30 fps
- 音频 AAC 128 kbps
- 开启 faststart（支持边下边播）

## 设计系统

- 底色 `cream #F9F4EB`
- 文字 `dark #1A1C1C`
- 唯一强调色 `lime #D0FF7E`，仅用于功能性高亮（进度条 / CTA / 提示词编号 / 筛选激活态）
- 避免装饰位使用彩色，保持整站视觉统一
