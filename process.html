[ PROCESS · 六步流水线 ]

从一条爆款到一条成片

上游不干净，下游一定崩。这套流程的成败，几乎都压在第 2 步和第 3 步。

01 找到「想买」发生的那一秒

拆解竞品爆款视频

把一条已经跑通的爆款视频上传给大模型，让它还原出完整的时间轴与逐句文案， 并定位用户产生购买冲动的具体秒数与诱因。

输入竞品爆款视频 MP4 输出时间轴脚本 + 冲动时刻 工具GPT
  • 得到可对照的时间轴与逐句文案
  • 定位「想买冲动」发生在第几秒，并归因：画面 / 文案 / 音效 / 评论区引导 / 其他
  • 这个「冲动时刻」是后面脚本迁移必须原样保留的锚点
Prompt · 01 
详细拆解该视频脚本，包括时间轴和文案，并分析这条视频里，用户产生"想买"冲动的具体时刻是第几秒，原因是（画面 / 文案 / 音效 / 评论区引导 / 其他）。
02 换产品，不换骨架

迁移成自有产品脚本

保留竞品的节奏、镜头转换、人物形象与冲动时刻，只把产品、成分与本地化场景替换掉。 输出结构固定为：一个问题 + 一个生活场景 + 一个产品动作 + 一个 CTA。

输入产品图 + 成分功效 输出自有产品版爆款脚本 工具GPT
  • 首次需完整介绍产品成分与功效；同一对话内跑通后，模型能记住上下文，后续可直接用简化指令
  • 结尾定格画面固定：一只手展示产品正面包装，另一只手指指向画面左下角
  • 本地化场景、语言与目标市场同步迁移，不要照搬原片语境
Prompt · 02 · 完整版 
根据产品成分组成和产品功效（成分与功效说明），并迁移原视频脚本节奏（画面风格、人物形象、核心结构、本地化场景）与用户"想买"的冲动时刻，输出一份专属 [产品名] 版本的爆款脚本（一个问题＋一个生活场景＋一个产品动作＋一个 CTA），脚本最后的画面定格在人物一只手展示产品正面包装，另一只手指指向画面左下角。
Prompt · 02 · 简化版（跑通后） 
迁移上传的视频文件脚本节奏、镜头转换、人物形象/动作、用户"想买"的冲动时刻，输出一份专属 [产品名] 产品版本的爆款脚本。
03 画面里不能有多余的东西

生成清洁版故事板

按脚本的完整时间轴，输出竖版分镜图。核心是「清洁」： 除产品包装外，画面里不出现任何文字与箭头符号—— 画上去的东西，视频生成时会原样长出来。

输入脚本 + 产品图 输出竖版清洁故事板 工具GPT
  • 人物统一：成年形象、成熟面容、成年身材比例，不出现稚嫩幼态的脸，且非真人形象
  • 人物前后保持一致，画面风格统一为高饱和、电影级 Q 版 3D
  • 出错时的两种修法：① 在原对话框重新点一次发送，整体重生成；② 针对不正确的产品包装单独修改
Prompt · 03 
严格按照 [脚本名] 的完整时间轴脚本内容，输出清洁版的竖版故事板（人物全都是成年形象、成熟的面容、成年身材比例，不出现稚嫩幼态的脸，但不是真人形象，人物前后保持一致，除了产品包装外不出现任何文字，画面风格为高饱和、电影级 Q 版 3D）。
04 把分镜翻译成机器语言

生成视频 Prompt

把故事板情节拆成多个 15 秒镜头，逐段生成可直接投喂视频模型的标准 Prompt。 每段都独立完整、不依赖前文， 并绑定固定人物形象与固定音色标签。

输入清洁版故事板 输出镜头级 Prompt 组 工具GPT
  • 节奏：TikTok 快节奏，画面自然流畅，人物对口型说目标语言文案
  • 每个情节的高潮部分配上夸张音效，人物使用固定音色
  • 因为已内含音效，后续剪辑阶段可以不加背景音乐
  • Prompt 格式要求：对应故事板第几格 + 固定人物形象 + 音色标签 + 镜头级细分
Prompt · 04 
严格按照上传的故事板，将故事板的情节拆分成 [N] 个 15 秒画面，TikTok 快节奏，画面自然流畅，要求生成的视频人物要对口型，说 [目标语言] 文案（对应 [脚本名]），视频画面为高饱和、电影级 Q 版 3D 风格，每个情节的高潮部分用上夸张的音效，人物有对应的固定音色，直接输出适合 [模型名] 的标准 Prompt 格式（每一段 Prompt 都是独立完整的，不依赖前文：对应故事板第几格画面、固定人物形象、固定人物对应音色标签版、按每段再细拆成镜头级 Prompt）。
05 参考图决定一致性

生成 AI 视频画面

把故事板、产品图与对应 Prompt 一起投给视频生成模型，逐段出画面。 关键在于同时给参考图—— 这是保证人物与包装前后一致的主要手段。

输入故事板 + 产品图 + Prompt 输出分段视频素材 工具TK 广告后台 / 即梦
  • 即梦路径：视频生成 → 全能参考 → 上传故事板、产品图、Prompt
  • 逐段生成，一段对应一格故事板，不要一次性丢整条
  • 跑出异常片段时，优先检查参考图是否被正确识别
Prompt · 05 
使用第 04 步生成的对应 Prompt，配合故事板与产品图作为参考输入，逐段生成画面。若使用即梦：选择「视频生成 - 全能参考」，上传故事板、产品图与 Prompt 后生成。
06 最后一道人工关

拼接成片与交付

把所有分段画面按时间轴拼起来、上字幕、导出成片。 字幕必须人工逐句核对—— 自动识别并非 100% 准确，尤其是口播语种与产品名的部分。

输入分段视频素材 输出完整成片 工具剪映 CapCut
  • 按脚本时间轴顺序拼接，检查镜头衔接是否跳帧
  • 字幕人工复核，重点核对产品名、成分名与口播语种
  • 音效已在生成阶段加入，可不加背景音乐；如需 BGM，注意不要压过人声

[ WATCH OUT ]

六个必踩的坑

这些是流程里最容易翻车的地方。每一条背后，都是一次返工换来的。

01 / 合规

绝对化与药品化用语

功效宣称一旦越线，素材会被直接拒审。提前在脚本阶段就替换掉高危词。

燃脂→辅助脂肪代谢
阻断→拦截 / 延缓吸收
02 / 一致性

人物形象幼态化

不写明年龄约束，模型很容易生成稚嫩幼态的脸，直接影响成片质感和投放效果。

成年形象 + 成熟面容 + 成年身材比例
03 / 画面

故事板里画了箭头和文字

故事板上出现的每一个符号都会被视频模型当成画面内容生成出来，最后变成画面里的脏东西。

清洁版 = 除产品包装外无任何文字与符号
04 / 生成

包装错位与人物扭曲

参考图没被正确识别时的典型症状。要么整体重生成，要么单独修包装，不要硬用。

原对话重新发送 / 包装单独修改
05 / 交付

字幕直接信任自动识别

自动字幕准确率不是 100%，产品名、成分名、口播语种是最常出错的三类。

逐句人工核对后再导出
06 / 声音

重复叠加背景音乐

生成阶段已经内置了高潮音效，剪辑时再加 BGM 容易糊成一团，甚至压过人声。

内含音效时可不加 BGM
